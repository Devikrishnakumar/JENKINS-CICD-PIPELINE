\# Jenkins CI/CD Pipeline



\## Objective



This project demonstrates a basic CI/CD pipeline using Jenkins and Docker to automatically build, test, and deploy a Node.js application.



\## Technologies Used



\- Jenkins

\- Docker

\- Node.js

\- Express.js

\- Jest

\- Supertest

\- GitHub

\- AWS EC2
